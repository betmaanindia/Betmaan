BETMAAN INDIA HOMEPAGE

Files:
- index.html: standalone informational homepage (no blog post list)
- assets/style.css: responsive styling

Setup:
1. Extract this ZIP.
2. Replace index.html in your GitHub repository with this file.
3. Replace assets/style.css with the included stylesheet.
4. Before publishing, replace YOUR-NETLIFY-SITE in the canonical URL inside index.html with your actual Netlify subdomain.
5. Commit changes; Netlify should deploy automatically if connected to GitHub.

Links labelled Betmaan Reviews point to https://betmaanreviews.com/ as requested.
Images and fonts load from external services and require an internet connection.
Check that all page links (privacy-policy.html, terms.html, responsible-gaming.html) exist in your repo.
